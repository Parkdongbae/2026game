# PRD — 동신중 학생 게임 갤러리

작성일: 2026-11-24

## 1. 배경과 목적

수업에서 학생들이 AI로 만든 HTML 게임을 구글 드라이브 폴더에 제출하고 있다. 파일을 하나씩 내려받아 열어야 해서 서로의 작품을 보기 어렵다.
제출된 게임을 한 화면에 모아 **누가 만들었는지 보여 주고, 바로 플레이하고, 좋아요로 반응**할 수 있는 웹 갤러리를 만든다.

## 2. 사용자

| 사용자 | 하는 일 | 계정 |
|---|---|---|
| 학생 | 게임 구경·플레이, 좋아요 | 학교 구글 계정 `@dongshin.ms.kr` |
| 교사(운영자) | 제출 폴더 관리, 배포, 숨김 처리 | 드라이브·GitHub·Vercel·Firebase 소유자 |
| 외부 방문자 | 구경·플레이만 가능 | 로그인 없음 |

## 3. 요구사항

| # | 요구사항 | 우선순위 |
|---|---|---|
| R1 | 드라이브 폴더의 HTML 게임을 갤러리 카드로 표시한다 | 필수 |
| R2 | 카드에 제작자를 `학번 이름` 형식으로 표시한다 (예: `3115 전예찬`) | 필수 |
| R3 | 카드를 누르면 **새 창**에서 해당 게임이 열린다 | 필수 |
| R4 | 게임마다 좋아요 버튼과 좋아요 수를 표시한다 | 필수 |
| R5 | 좋아요는 `@dongshin.ms.kr` 구글 계정으로 로그인한 사람만 누를 수 있다 | 필수 |
| R6 | 한 계정은 한 게임에 좋아요를 1개만 줄 수 있다 (다시 누르면 취소) | 필수 |
| R7 | 학생이 폴더에 파일을 추가하면 **교사가 아무것도 하지 않아도** 갤러리에 반영된다 | 필수 |
| R8 | 급할 때는 더블클릭 한 번으로 즉시 배포할 수 있다 | 필수 |
| R9 | 인기순·최신순·학번순 정렬, 이름·제목 검색 | 권장 |
| R10 | 새로 올라온 게임에 NEW 표시, 인기 1~3위 표시 | 권장 |
| R11 | 교사가 특정 게임을 숨기거나 제목을 고칠 수 있다 | 권장 |

## 4. 범위 밖 (이번에 하지 않는 것)

- 학생이 사이트에서 직접 파일을 올리는 기능 (제출은 계속 드라이브 폴더로)
- 댓글, 별점, 신고
- 게임 썸네일 자동 캡처
- 게임 내용 심의 자동화 (교사가 숨김 처리로 대응)

## 5. 시스템 구성

```
구글 드라이브 폴더 (학생 제출)
        │  scripts/sync.mjs  (10분마다 GitHub Actions / 또는 배포.bat)
        ▼
GitHub 저장소  ──push──▶  Vercel 프로젝트 2개
   site/  갤러리 화면  ─────▶  갤러리 주소
   play/  학생 게임 파일 ───▶  게임 주소 (갤러리와 다른 주소)

갤러리 화면 ──▶ Firebase 인증(구글 로그인) + Firestore(좋아요)
```

게임을 갤러리와 **다른 주소**에서 여는 이유: 학생 코드가 갤러리와 같은 주소에서 실행되면 로그인한 방문자의 권한으로 좋아요를 대신 누르는 코드를 넣을 수 있다. 주소를 분리하면 게임은 로그인 정보에 접근할 수 없다. (상세: `01_핵심로직_규칙명세서.md` 6장)

## 6. 성공 기준

- 폴더에 파일을 넣은 뒤 20분 안에 갤러리에 카드가 나타난다.
- 학교 계정이 아닌 계정으로는 좋아요가 저장되지 않는다 (화면 차단 + 서버 규칙 차단).
- 같은 계정으로 같은 게임에 좋아요를 두 번 저장할 수 없다.
- 교사가 평소에 해야 할 일이 0개다.
