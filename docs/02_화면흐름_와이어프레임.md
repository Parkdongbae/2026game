# 2. 화면 흐름도 및 와이어프레임

> **개정 (2026-11-24, 2차 디자인)** — 캔바 시안 "네온 아케이드"로 다시 만들었다. 아래 와이어프레임의 구성 요소 규칙은 그대로이고, 다음이 바뀌었다.
> - 어두운 남보라 배경 + 네온 분홍/보라. 밝은 화면 모드는 없앴다.
> - 머리글 아래에 **히어로 영역**(큰 제목, 통계 칩 `게임` `좋아요` `내가 누른 ♥`)이 생겼다. 요약 글자는 통계 칩으로 옮겼다.
> - 히어로와 도구 줄 사이에 **"⚠️ 다시 제출이 필요해요" 안내 상자**가 생겼다(해당 파일이 있을 때만 보임, 기본 펼침). 학번·이름, 이유, 고치는 방법을 보여 준다.
> - 카드 그림은 색 배경 + 첫 글자 대신 **캔바에서 만든 표지 그림 6종**(`site/assets/cover1~19.jpg`, 2차로 13종 추가)을 쓴다. 제목에 어울리는 그림을 먼저 주고 나머지는 덜 쓰인 그림을 돌려 쓴다. 제목이 이모지로 시작하면 그 이모지를 그림 오른쪽 아래에 겹쳐 보여 준다.
> - 배너 그림: `site/assets/hero.jpg` (캔바 생성).
> - 캔바 시안: https://canva.link/743j7nxm581gml6

목적: 화면은 갤러리 한 장뿐이다. 학생이 **게임을 찾고 → 열고 → 돌아와 좋아요**를 누르는 흐름이 끊기지 않게 배치한다.

## 1. 화면 흐름

```
[갤러리 접속]
     │  games.json 읽기 → 카드 표시 (로그인 없이 바로)
     │  좋아요 수 읽기 → 숫자 채움
     ▼
[갤러리] ──카드 클릭──▶ [새 창: 게임]   (갤러리 창은 그대로 남음)
     │
     ├─ ♥ 클릭 (로그인됨, 학교 계정) ──▶ 즉시 ♥ 채움 +1 → 저장
     │
     ├─ ♥ 클릭 (로그인 안 됨) ──▶ [구글 로그인 팝업]
     │        ├─ 학교 계정 ──▶ 로그인 완료 → 방금 누른 ♥ 자동 반영
     │        └─ 다른 계정 ──▶ 자동 로그아웃 + 안내 메시지
     │
     └─ ♥ 다시 클릭 ──▶ 좋아요 취소 -1
```

로그인은 **좋아요를 누르는 순간에만** 요구한다. 구경과 플레이는 로그인 없이 된다.

## 4. 구성 요소 규칙

| 요소 | 규칙 |
|---|---|
| 카드 | 카드 전체(♥ 버튼 제외)가 링크. 새 창으로 열림 |
| 카드 그림 | 썸네일 없음. 게임 ID로 정해지는 고정 그라데이션 + 제목 첫 글자(또는 제목의 이모지). 같은 게임은 항상 같은 색 |
| 제작자 | `학번 이름`. 제목보다 작지만 항상 보임 (R2) |
| ♥ 버튼 | 안 누름 `♡ 숫자`(테두리) / 누름 `♥ 숫자`(채움, 분홍). 누를 수 있는 영역 44px 이상 |
| 정렬 버튼 | 3개 중 1개 선택. 선택 상태는 새로고침해도 유지(localStorage) |
| 로그인 버튼 | 로그아웃 상태 `학교 계정 로그인` / 로그인 상태 `이름 · 로그아웃` |
| 알림(토스트) | 화면 아래 가운데, 3초 후 사라짐 |

## 5. 상태별 화면

| 상태 | 표시 |
|---|---|
| 게임 목록 읽는 중 | 회색 뼈대 카드 8개 |
| 좋아요 수 읽는 중 | 숫자 자리에 `·` |
| 게임 0개 | "아직 올라온 게임이 없어요" |
| 검색 결과 없음 | "'검색어'에 맞는 게임이 없어요" |
| 좋아요 수 읽기 실패 | 카드는 그대로, 숫자 `-`, 토스트 "좋아요를 불러오지 못했어요" |
| 다른 도메인 로그인 | 토스트 "학교 계정(@dongshin.ms.kr)으로만 좋아요를 누를 수 있어요" |
| 좋아요 저장 실패 | 숫자·하트 원래대로 + 토스트 "저장하지 못했어요. 다시 눌러 주세요" |
| 팝업 차단됨 | 토스트 "팝업을 허용한 뒤 다시 눌러 주세요" |

## 6. 접근성·기본기

- 키보드: Tab으로 카드·♥ 이동, Enter로 실행. 포커스 테두리 표시.
- ♥ 버튼에 `aria-pressed`, `aria-label="전예찬의 게임 좋아요, 현재 12개"`.
- 움직임 줄이기 설정(`prefers-reduced-motion`)이면 하트 애니메이션 생략.
- 밝은 화면·어두운 화면 모두 지원(시스템 설정 따름).
