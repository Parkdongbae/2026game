# 4. 피드백·게이미피케이션 기획서

목적: 좋아요를 누르는 재미와, 자기 게임이 반응을 얻는 보람을 준다. 동시에 **경쟁이 과열되거나 소외되는 학생이 생기지 않게** 한다.

## 1. 즉각 피드백

| 행동 | 피드백 | 시간 |
|---|---|---|
| ♥ 누름 | 하트가 1.3배로 튀었다 돌아옴 + 분홍으로 채워짐 + 숫자 +1, 작은 하트 6개가 위로 흩어짐 | 0.4초 |
| ♥ 취소 | 하트가 살짝 줄었다 돌아옴 + 테두리만 남음 + 숫자 -1 | 0.2초 |
| 카드에 마우스 올림 | 카드가 4px 떠오르고 `▶ 플레이` 강조 | 0.15초 |
| 로그인 성공 | 토스트 "○○○님, 환영해요! 마음에 드는 게임에 ♥를 눌러 주세요" | 3초 |
| 저장 실패 | 원래 상태로 되돌리고 토스트 | 3초 |

- 숫자는 서버 응답을 기다리지 않고 먼저 바꾼다(낙관적 반영). 체감 지연 0.
- 소리는 넣지 않는다 (교실에서 여러 명이 동시에 사용).
- 움직임 줄이기 설정이면 색·숫자만 바뀐다.

## 2. 순위와 배지

| 배지 | 조건 | 위치 |
|---|---|---|
| 🥇 🥈 🥉 | 좋아요 1개 이상인 게임 중 1~3위 (동점은 같은 메달) | 카드 왼쪽 위 |
| NEW | 등록 후 72시간 이내 | 카드 오른쪽 위 |

- 4위 이하는 **순위 숫자를 보여 주지 않는다.** 꼴찌가 드러나지 않게 하기 위함.
- 좋아요 0개인 게임에는 `♡ 0` 대신 `♡` 만 보여 준다.

## 3. 골고루 보게 하는 장치

| 장치 | 내용 |
|---|---|
| 기본 정렬 | 인기순. 단, 좋아요가 같은 게임끼리는 최신 등록 순 |
| 최신순 버튼 | 늦게 낸 학생의 게임도 맨 위에 올 기회 |
| NEW 배지 | 새 게임에 시선 유도 |
| 내 좋아요 표시 | 내가 누른 게임은 채워진 하트 → 아직 안 해 본 게임이 한눈에 보임 |

## 4. 머리글 요약

`게임 9개 · 좋아요 132개` — 반 전체가 함께 쌓아 가는 숫자를 보여 준다. 로그인하면 `내가 누른 ♥ 4/9` 를 추가로 보여 줘서 전부 해 보도록 유도한다.

## 5. 공정성

| 우려 | 대응 |
|---|---|
| 한 사람이 여러 번 누르기 | 문서 ID 구조로 불가능 (`01` 문서 3.2) |
| 학교 밖 계정으로 누르기 | 보안 규칙이 거부 |
| 게임 코드가 방문자 대신 좋아요 누르기 | 게임을 다른 주소에서 실행 (`01` 문서 6장) |
| 자기 게임에 좋아요 | 허용 (1개뿐이라 영향 작음) |
| 친구끼리 몰아주기 | 기술적으로 막지 않음. 수업 안내로 대응 |

## 6. 이번에 넣지 않는 것

댓글, 플레이 횟수, 반별 대항전, 주간 랭킹, 좋아요 알림. 필요해지면 `05` 문서의 2차 범위에서 검토한다.
