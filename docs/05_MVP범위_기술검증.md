# 5. MVP 범위 및 기술 검증(PoC)

목적: 무엇을 먼저 내고 무엇을 미룰지 정하고, 막힐 수 있는 지점을 미리 확인한다.

## 1. 범위

| 구분 | 항목 |
|---|---|
| **MVP (지금)** | 갤러리 카드, 학번·이름 표시, 새 창 플레이, 구글 로그인, 학교 도메인 제한 좋아요(1인 1게임 1개·취소), 인기/최신/학번 정렬, 검색, NEW·메달, 드라이브 자동 동기화(10분), 더블클릭 배포, 숨김·제목 수정 |
| 2차 (요청 시) | 게임 썸네일 자동 캡처, 반별 보기, 플레이 횟수, 교사용 관리 화면 |
| 하지 않음 | 사이트 내 파일 업로드, 댓글, 실시간 채팅 |

## 2. 결정 사항

| 주제 | 선택 | 버린 대안과 이유 |
|---|---|---|
| 게임 목록 저장 | 저장소의 `games.json` | Firestore에 목록 저장 — 배포 없이 추가되지만 드라이브 파일을 브라우저가 직접 읽을 수 없어 어차피 복사가 필요 |
| 좋아요 저장 | Firestore + 보안 규칙 | localStorage — 도메인 제한·중복 방지 불가 |
| 좋아요 수 | 집계 `count()` | 카운터 문서 — 규칙이 복잡해지고 조작 여지 생김 |
| 게임 실행 위치 | 별도 Vercel 프로젝트(다른 주소) | 같은 주소 + sandbox — 게임의 최고 기록 저장(localStorage)이 깨짐 (10개 중 6개가 사용) |
| 자동 반영 | GitHub Actions 예약 실행 | 드라이브 API 웹훅 — 인증·서버가 필요해 과함 |
| 프레임워크 | 없음 (HTML 1장 + Firebase CDN) | React 등 — 빌드 단계가 생겨 운영이 무거워짐 |

## 3. 기술 검증 결과

| # | 확인할 것 | 방법 | 결과 |
|---|---|---|---|
| P1 | 로그인 없이 드라이브 폴더 목록을 읽을 수 있나 | `drive.google.com/embeddedfolderview?id=…` 요청 | ✅ 10개 파일의 ID·이름 확인 (2026-11-24) |
| P2 | 로그인 없이 파일을 내려받을 수 있나 | `drive.google.com/uc?export=download&id=…` | ✅ 10개 모두 원본 크기 그대로 받음 (최대 2.5MB) |
| P3 | 파일명에서 학번·이름이 나오나 | 정규식 적용 | ✅ 10개 모두 추출 (`염 성 빈` 공백 포함 사례 처리) |
| P4 | 게임이 아닌 파일이 섞여 있나 | 내용 확인 | ⚠️ 1개 (3109 오예준 — Gemini 대화 페이지 저장본). 자동 제외 규칙 추가 |
| P5 | 게임이 외부 자원을 쓰나 | `src="http…"` 검색 | Tailwind CDN 5개, cdnjs 1개 — 인터넷만 되면 동작 |
| P6 | 게임이 저장 공간을 쓰나 | `localStorage` 검색 | 6개 사용 → 게임 주소 분리 방식 채택 근거 |
| P7 | 도메인 제한이 서버에서 강제되나 | 보안 규칙 + 다른 계정으로 쓰기 시도 | 배포 후 확인 (`운영가이드.md` 점검표) |
| P8 | Actions가 푸시하면 Vercel이 배포하나 | 실제 실행 | 배포 후 확인 |

## 4. 위험과 대응

| 위험 | 가능성 | 영향 | 대응 |
|---|---|---|---|
| 드라이브 공개 목록 화면 구조가 바뀜 (비공식 경로) | 낮음 | 자동 반영 중단 | 결과 0개면 아무것도 지우지 않고 실패 처리 → Actions 실패 메일. `배포.bat` 로 파일을 직접 `inbox/` 에 넣어 배포하는 우회로 제공 |
| 폴더 공유가 "링크가 있는 모든 사용자"에서 바뀜 | 중간 | 자동 반영 중단 | 위와 같음. 운영가이드에 공유 설정 명시 |
| 파일 100개 초과 (목록 한 번에 다 안 나올 수 있음) | 낮음 | 일부 누락 | 학급 단위 사용 가정. 50개 넘으면 폴더를 반별로 나누고 폴더 ID를 여러 개 등록 |
| Actions 예약 실행 지연 (보통 5~15분, 혼잡 시 더) | 높음 | 반영이 늦음 | `배포.bat` 또는 Actions "Run workflow" 버튼으로 즉시 실행 |
| 저장소 60일 무활동 시 예약 실행 자동 중지 | 방학 중 | 자동 반영 중단 | 운영가이드에 재활성화 방법 기재 |
| 학교 구글 관리자가 외부 앱 로그인 차단 | 중간 | 학생 로그인 불가 | 관리 콘솔에서 앱 허용 필요. 교사 계정으로 먼저 시험 |
| 부적절한 게임 내용 | 중간 | 민원 | `overrides.json` 의 `hide` 로 즉시 내림 |
| 학생 이름·학번이 공개 사이트·공개 저장소에 노출 | 확정 | 개인정보 | 교사 결정 사항(학번+이름 표시, 저장소 공개). 필요 시 표시 형식만 바꾸면 됨 |
| 게임끼리 localStorage 키 충돌 | 낮음 | 최고 기록이 섞임 | 수용. 문제 생기면 게임별 하위 주소 분리 검토 |

## 5. 출시 점검표

- [ ] 갤러리 주소에서 카드 9개가 보인다
- [ ] 카드 클릭 시 새 창에서 게임이 열리고 주소가 게임 주소다
- [ ] 학교 계정 로그인 → ♥ → 새로고침 후에도 유지
- [ ] 같은 게임 ♥ 다시 누르면 취소
- [ ] 학교 밖 계정 로그인 → 차단 안내, 좋아요 저장 안 됨
- [ ] 드라이브에 시험 파일 추가 → 자동 반영
- [ ] `배포.bat` 더블클릭 → 반영
