# 작업 지시서 — 갤러리 화면 `site/index.html`

## 목표
학생 게임 갤러리 한 장짜리 화면. 빌드 도구 없이 HTML 파일 1개(CSS·JS 내장)로 만든다.
출력은 **`site/index.html` 파일 내용 전체만**. 설명 문장 금지.

## 입력 데이터

1. `<script src="./config.js"></script>` 가 `window.APP_CONFIG` 를 만든다.
   ```js
   window.APP_CONFIG = {
     allowedDomain: "dongshin.ms.kr",
     playBase: "https://example-play.vercel.app/",   // 끝에 / 있음
     firebase: { apiKey:"", authDomain:"", projectId:"", appId:"" }  // apiKey 가 빈 문자열일 수 있음
   };
   ```
2. `fetch("./games.json", {cache:"no-store"})`
   ```json
   { "updatedAt":"ISO", "games":[ { "id":"3115", "studentNo":"3115", "name":"전예찬",
       "title":"🎱 클래식 8-BALL", "file":"3115.html", "addedAt":"ISO", "updatedAt":"ISO" } ] }
   ```

## Firebase
- `<script type="module">` 안에서 CDN ESM 사용. 버전 10.14.1 고정.
  - `https://www.gstatic.com/firebasejs/10.14.1/firebase-app.js` : initializeApp
  - `.../firebase-auth.js` : getAuth, GoogleAuthProvider, signInWithPopup, signOut, onAuthStateChanged
  - `.../firebase-firestore.js` : getFirestore, collection, doc, query, where, getDocs, getCountFromServer, setDoc, deleteDoc, serverTimestamp
- `APP_CONFIG.firebase.apiKey` 가 비어 있으면 Firebase 를 초기화하지 않는다. 카드는 정상 표시, 로그인 버튼 숨김, ♥ 누르면 토스트 "좋아요 기능 준비 중이에요".
- Firebase import 는 **동적 import()** 로 하고 try/catch 로 감싼다. 실패해도 카드 목록은 보여야 한다.

## 좋아요 규칙 (반드시 그대로)
- 컬렉션 `likes`, 문서 ID `${gameId}_${uid}`, 필드 정확히 `{ gameId, uid, createdAt: serverTimestamp() }` (다른 필드 넣으면 서버가 거부함).
- 좋아요: `setDoc(doc(db,"likes",`${gameId}_${uid}`), {...})` / 취소: `deleteDoc(같은 문서)`.
- 게임별 수: `getCountFromServer(query(collection(db,"likes"), where("gameId","==",id)))` 를 게임마다 병렬 실행(`Promise.allSettled`). 실패한 게임은 수를 `null` 로 두고 `-` 표시.
- 내가 누른 게임: 로그인되면 `getDocs(query(collection(db,"likes"), where("uid","==",uid)))` → gameId 집합.
- 로그인: `GoogleAuthProvider` 에 `setCustomParameters({ hd: allowedDomain, prompt: "select_account" })`, `signInWithPopup`.
- `onAuthStateChanged` 에서 `user.email` 이 `"@"+allowedDomain` 으로 끝나지 않으면(소문자 비교) 즉시 `signOut` 하고 토스트 "학교 계정(@dongshin.ms.kr)으로만 좋아요를 누를 수 있어요" (도메인은 config 값 사용).
- 로그인 안 된 상태에서 ♥ 를 누르면: 누른 gameId 를 기억 → 로그인 팝업 → 성공하면 그 게임에 좋아요 자동 적용(이미 눌려 있던 게임이면 아무것도 안 함).
- 낙관적 반영: 누르는 즉시 하트·숫자 변경, 저장 실패 시 원상 복구 + 토스트 "저장하지 못했어요. 다시 눌러 주세요". 같은 게임에 요청 진행 중이면 추가 클릭 무시.
- 팝업 오류 코드 `auth/popup-blocked` → 토스트 "팝업을 허용한 뒤 다시 눌러 주세요". `auth/popup-closed-by-user`, `auth/cancelled-popup-request` 는 조용히 무시.

## 화면
구성: 머리글(고정) / 도구 줄 / 카드 격자 / 바닥글. 한국어. 시스템 글꼴(`system-ui, "Pretendard", "Malgun Gothic", sans-serif`).

- 머리글: 왼쪽 `🎮 동신중 게임 갤러리`, 가운데 요약 `게임 N개 · 좋아요 M개` (로그인 시 ` · 내가 누른 ♥ a/N` 추가), 오른쪽 로그인 버튼.
  - 로그아웃 상태: `학교 계정 로그인` / 로그인 상태: `{displayName} · 로그아웃`
- 도구 줄: 검색 입력(placeholder `제목·이름·학번 검색`), 정렬 버튼 3개 `인기순` `최신순` `학번순` (`aria-pressed`). 선택은 `localStorage["gallery.sort"]` 에 저장, 기본 인기순. localStorage 접근은 try/catch.
- 카드 격자: `grid-template-columns: repeat(auto-fill, minmax(230px, 1fr))`, 600px 이하에서는 2열 고정.
- 카드:
  - 위쪽 그림 영역(비율 16:10): 게임 id 문자열 해시로 고른 색상(hue) 2개의 그라데이션 + 가운데 큰 글자(제목이 이모지로 시작하면 그 이모지, 아니면 제목 첫 글자). 같은 id 는 항상 같은 색.
  - 왼쪽 위 메달(🥇🥈🥉), 오른쪽 위 `NEW` 배지.
  - 제목(최대 2줄 말줄임), 제작자 `3115 전예찬` (학번 + 공백 + 이름).
  - 아래 줄: `▶ 플레이` 표시와 ♥ 버튼.
  - 카드 전체는 `<a href="{playBase}{file}" target="_blank" rel="noopener noreferrer">`. ♥ 버튼은 `<a>` **바깥**의 별도 `<button>` (링크 안에 버튼을 넣지 말 것). 배치는 CSS position 으로 처리.
  - ♥ 버튼: 안 누름 `♡ 3`, 누름 `♥ 3`(분홍 채움). 수가 0이면 숫자 생략, 읽는 중 `·`, 실패 `-`. 최소 44×44px. `aria-pressed`, `aria-label="{이름}의 게임 좋아요, 현재 {n}개"`.
- 정렬:
  - 인기순: 좋아요 내림차순(null 은 0 취급) → 같으면 addedAt 최근순
  - 최신순: addedAt 최근순
  - 학번순: studentNo 오름차순 → id 오름차순
- 메달: 좋아요 ≥ 1 인 게임들의 서로 다른 좋아요 값 중 상위 3개 값에 🥇🥈🥉 (동점은 같은 메달). 정렬 방식과 무관하게 표시.
- NEW: `Date.now() - addedAt < 72시간`.
- 검색: 제목·이름·학번을 합친 문자열에 대해, 양쪽 모두 공백 제거·소문자화 후 포함 여부.
- 상태 표시:
  - 목록 읽는 중: 뼈대 카드 8개
  - 게임 0개: `아직 올라온 게임이 없어요`
  - 검색 결과 없음: `'{검색어}'에 맞는 게임이 없어요`
  - games.json 읽기 실패: `게임 목록을 불러오지 못했어요. 새로고침해 주세요.`
- 토스트: 화면 아래 가운데, 3초 후 사라짐, `role="status" aria-live="polite"`.
- 바닥글: `좋아요는 @{allowedDomain} 계정으로 게임마다 1번 누를 수 있어요.`
- 효과: ♥ 누를 때 하트 scale 1→1.3→1 (0.4초) + 작은 하트 6개가 위로 흩어지며 사라짐. 카드 hover 시 4px 상승. `@media (prefers-reduced-motion: reduce)` 에서는 애니메이션 없음.
- 색: 밝은/어두운 화면 모두 지원(`prefers-color-scheme`), CSS 변수 사용. 포인트 색 분홍 `#ff4d7d`.
- 키보드 포커스 테두리(`:focus-visible`) 표시.

## 보안·품질 (하지 말 것)
- games.json 의 문자열(제목·이름)을 `innerHTML` 에 넣지 말 것. 반드시 `textContent` / `createElement` 사용.
- `file` 값은 `/^[0-9A-Za-z_-]+\.html$/` 에 맞을 때만 링크 생성, 아니면 그 게임은 건너뜀.
- 외부 라이브러리·폰트·이미지 추가 금지 (Firebase CDN 만 허용).
- 이메일을 Firestore 에 저장하지 말 것.
- `alert()` 사용 금지.

## 완료 조건
- `config.js` 의 apiKey 가 빈 값이어도 콘솔 오류 없이 카드가 표시된다.
- 카드 클릭 → 새 탭으로 `{playBase}{file}` 이 열린다. ♥ 클릭은 새 탭을 열지 않는다.
- 정렬·검색·메달·NEW 가 위 규칙대로 동작한다.
- 폭 375px 에서 가로 스크롤이 생기지 않는다.
