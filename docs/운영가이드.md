## 학생이 게임을 추가했을 때

### 방법 1 — 아무것도 안 한다 (기본)

GitHub Actions가 10분마다 제출 폴더를 확인해서 새 파일·바뀐 파일·지운 파일을 자동으로 반영한다.
폴더에 파일이 들어간 뒤 보통 10~20분 안에 갤러리에 나타난다.

### 방법 2 — 지금 바로 반영하고 싶을 때

둘 중 편한 것 하나.

- **PC에서**: `D:\2026game\배포.bat` 더블클릭. "완료!"가 보이면 1~2분 뒤 반영.
- **어디서나(휴대폰 포함)**: [Actions 페이지](https://github.com/Parkdongbae/2026game/actions/workflows/sync.yml) → `Run workflow` → `Run workflow`.

## 학생에게 안내할 제출 규칙

1. 게임이 들어 있는 **HTML 파일 1개**를 제출 폴더에 올린다.
2. 파일 이름 끝을 **`학번이름.html`** 로 끝낸다. 예) `내게임 - 3115전예찬.html`
3. AI 대화 화면에서 `Ctrl+S`로 저장한 파일은 게임이 아니다. 게임 코드를 HTML 파일로 내려받아(또는 복사해 저장해) 제출한다.
4. 고쳐서 다시 낼 때는 **옛 파일을 지우고** 새 파일을 올린다 → 좋아요가 그대로 유지된다.
   옛 파일을 남겨 두면 두 번째 작품(`3115-2`)으로 따로 올라간다.

## 올라오지 않은 파일 확인

잘못 올린 파일은 갤러리 맨 위 **"⚠️ 다시 제출이 필요해요"** 상자에 학번·이름, 이유, 고치는 방법과 함께 자동으로 표시된다.
학생이 고쳐서 다시 올리면 다음 동기화 때 상자에서 사라진다. 교사가 따로 알려 줄 필요가 없다.

저장소의 [`sync-report.json`](../sync-report.json) 에 건너뛴 파일과 이유가 적힌다. `배포.bat` 실행 화면에도 `!` 로 표시된다.

| 이유 | 조치 |
|---|---|
| 파일명에서 학번·이름을 찾지 못함 | 드라이브에서 파일 이름을 `…학번이름.html` 로 바꾼다 |
| AI 대화 화면 저장본 (게임 파일 아님) | 학생이 게임 HTML 파일로 다시 제출 |
| HTML 파일이 아님 | 학생이 다시 제출 |
| 내려받기 실패 | 다음 동기화 때 자동 재시도. 계속되면 파일 공유 설정 확인 |

## 게임 숨기기 / 제목 고치기

저장소 루트의 `overrides.json` 을 고친다 (GitHub 웹에서 연필 아이콘으로 바로 수정 가능). 저장하면 자동으로 반영된다.

```json
{
  "3113": { "hide": true },
  "3105": { "title": "새 제목" }
}
```

- 키는 게임 ID(카드 주소의 숫자, 보통 학번).
- 숨겨도 좋아요 기록은 남는다. 줄을 지우면 다시 나타난다.

## 좋아요 관리

- 누가 눌렀는지·몇 개인지: Firebase 콘솔 → Firestore Database → `likes`
- 전부 초기화: `likes` 컬렉션 삭제
- 허용 도메인 변경: `firestore.rules` 의 `dongshin[.]ms[.]kr` 과 `site/config.js` 의 `allowedDomain` 을 **둘 다** 고친 뒤
  `firebase deploy --only firestore:rules` 실행, 그리고 `배포.bat`

## 제출 폴더를 바꾸거나 추가할 때

`sync.config.json` 의 `folderIds` 에 폴더 ID(폴더 주소의 `folders/` 뒤 문자열)를 넣는다. 여러 개 가능.
폴더는 **"링크가 있는 모든 사용자 - 뷰어"** 로 공유되어 있어야 한다.

## 문제가 생겼을 때

| 증상 | 원인 | 해결 |
|---|---|---|
| 새 게임이 30분 넘게 안 올라옴 | Actions 지연 또는 실패 | Actions 페이지에서 빨간 표시 확인 → `배포.bat` 실행 |
| Actions가 아예 안 돎 | 저장소 60일 무활동 시 GitHub가 예약 실행을 끔 | Actions 페이지의 `Enable workflow` 클릭 |
| "목록을 읽지 못했습니다" | 폴더 공유가 바뀜 / 구글 화면 구조 변경 | 공유 설정 확인. 급하면 파일을 `D:\2026game\inbox\` 에 복사하고 `배포.bat` |
| 로그인 팝업에서 오류 `unauthorized-domain` | Firebase 승인된 도메인 누락 | 콘솔 → Authentication → 설정 → 승인된 도메인에 `dongshin-game-2026.vercel.app` 추가 |
| 학생 계정으로 로그인이 안 됨 | 학교 구글 관리자가 외부 앱 차단 | 관리 콘솔에서 앱 허용 |
| 좋아요가 "저장하지 못했어요" | 학교 계정이 아님 / 규칙 미배포 | 계정 확인, `firebase deploy --only firestore:rules` |

## 폴더 구조

```
site/        갤러리 화면 (index.html, config.js, games.json)   → Vercel: dongshin-game-2026
play/        학생 게임 파일 {ID}.html                          → Vercel: dongshin-game-2026-play
scripts/     sync.mjs (드라이브 → 저장소)
.github/     10분마다 sync.mjs 실행
docs/        기획 문서
overrides.json   숨김·제목 수정
sync.config.json 제출 폴더 ID
firestore.rules  좋아요 보안 규칙
배포.bat     즉시 배포
```
